# Golubev Coffee

Golubev Coffee is a static multi-page website for a fictional coffee shop brand.

The project started as a college assignment in January 2025 and later grew from a Google Sites page into a custom HTML/CSS/JavaScript website with its own visual style and GitHub Pages deployment.

## Live Website

[golubevcoffee.ru](https://golubevcoffee.ru)

## Pages

- Home page with video background
- Menu with category filtering
- Brand story page
- Coffee shop interior page
- Contacts page with map

## Features

- Responsive multi-page layout
- Reusable header and navigation components
- Fullscreen navigation overlay
- Menu filtering by category
- Custom mobile menu selector
- Interactive map with Leaflet
- Local Comfortaa font files
- Custom domain through GitHub Pages

## Tech Stack

- HTML
- CSS
- JavaScript
- Leaflet.js
- GitHub Pages
- Custom domain

## Project History

The first version of the idea was called CoffeeTime and was built with Google Sites for a college task. After the project was defended with an excellent grade, it stayed paused for more than a year.

In April 2026, I rebuilt the website from scratch using HTML, CSS, and JavaScript. Later, the project was rebranded as Golubev Coffee to make it feel more personal and closer to a real brand.

## My Role

I worked on the idea, visual direction, page structure, content, layout, JavaScript behavior, deployment, and project packaging for GitHub.

AI tools were used as an assistant during development and cleanup, but the project idea, history, visual direction, testing, and final decisions were mine.

This project is important to me because it shows how a simple study task can grow into a personal long-term project.

## Status

The project is a static frontend website. It does not include a backend or database.

Future improvements may include:

- order form
- admin panel
- database-backed menu
- better image and video optimization
