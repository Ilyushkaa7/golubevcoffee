# \# Golubev Coffee



#### Одностраничный сайт кофейни. Учебный проект, переросший в полноценный сайт на чистом HTML/CSS/JS.



##### \## Технологии

\- HTML5

\- CSS3 (Flexbox, Grid, CSS-переменные, анимации)

\- JavaScript (ES6+)

\- Leaflet.js (карта)

\- Google Fonts (шрифт Comfortaa, локально)



##### \## Страницы

\- Главная — видеофон и навигация

\- Меню — фильтрация по категориям (кофе, выпечка, десерты)

\- О бренде — история проекта

\- Наше заведение — фотогалерея

\- Контакты — карта и информация



##### \## Установка

git clone https://github.com/Ilyushkaa7/coffee-time.git

Открыть index.html в браузере.
